# Data for diffraction simulator

This directory is a placeholder simulated datasets for testing purposes.
The datasets are stored in NetCDF format and can be easily loaded using the `xarray` library in Python.
They must first be unzipped before use. (TODO (maffettone): include link for data download)
Included are the following datasets:

- `AlLiFe-diffraction.nc`: Simulated diffraction data for an Al-Li-Fe alloy.
- `BiCuV-diffraction.nc`: Simulated diffraction data for a Bi-Cu-V alloy.
- `LiSrAl-diffraction.nc`: Simulated diffraction data for a Li-Sr-Al alloy.
